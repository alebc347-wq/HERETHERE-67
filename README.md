# HERETHERE COFFEE

> **從此刻（HERE）到遠方（THERE）**：我們相信，每一杯咖啡都承載著一段故事。

以 **React 18 + Vite + Tailwind CSS + shadcn/ui** 打造的繁體中文精品咖啡品牌網站，結合 Framer Motion 動態設計、Moment 即時活動倒數、互動式 V60 手沖模擬彈窗，以及受密碼保護的全功能管理後台。

## 功能特色

- **首頁七大區塊**：Hero 呼吸動態全螢幕主視覺、品牌故事、最新咖啡誌文章、咖啡愛好者評語、快閃活動即時倒數預覽、電子報訂閱與重複驗證、LINE 官方加入引導與一鍵複製關鍵字。
- **精選商店 (`/shop`)**：分類篩選（全部 / 咖啡豆 / 濾掛包 / 器具）、3:4 直式商品卡片，點擊可開啟「手沖模擬動畫彈窗」檢視 V60 蒸氣滴濾動畫、四階段萃取解說、風味標籤與推薦沖煮參數。
- **咖啡誌部落格 (`/blog` & `/blog/:id`)**：分類篩選與關鍵字即時搜尋、文章詳情安全 HTML 渲染（DOMPurify 淨化）與上下篇導覽。
- **快閃活動 (`/flash`)**：多場次活動切換、即時天/時/分/秒倒數計時器、現場限定亮點與 Google 地圖導航。
- **管理後台 (`/admin`)**：
  - **密碼保護與改密碼功能**：預設密碼為 `HERETHERE`（透過 SHA-256 雜湊驗證並支援於「帳號安全」分頁自訂修改密碼與一鍵鎖定登出）。
  - **完整內容管理**：文章、商品、快閃活動、顧客評語的新增／編輯／刪除與上下架切換、訂閱者名單複製、品牌視覺 Logo 與圖片網址／本機上傳預覽。

## 本地開發與建置

```bash
npm install
npm run dev      # 啟動開發伺服器 (預設 http://localhost:5173)
npm run build    # 建置生產環境檔案
npm run lint     # 執行 oxlint 程式碼檢查
```
